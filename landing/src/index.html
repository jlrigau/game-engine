[[How it works||Le principe]]

[[A game = the engine + a sheet + drawings||Un jeu = le moteur + une fiche + des dessins]]

[[The engine already knows how to do everything: move a character, look after creatures, ride a horse, drive, race, run a shop, save the game… Each game is just a description sheet saying which of these systems to switch on, with which texts and which drawings.||Le moteur sait déjà tout faire : déplacer un personnage, soigner des créatures, monter à cheval, conduire, faire une course, gérer une boutique, sauvegarder la partie… Chaque jeu n'est qu'une fiche de description qui dit lequel de ces systèmes allumer, avec quels textes et quels dessins.]]

[[The engine||Le moteur]]

[[Every game system, generic. It holds no game content and it is identical in every game.||Tous les systèmes de jeu, génériques. Il ne contient aucun contenu de jeu et il est identique dans tous les jeux.]] engine.js

// [[From the Nebula Nursery sheet:||Extrait de la fiche de Nebula Nursery :]]
// [[one creature and two actions, described, not coded.||une créature et deux actions, décrites, pas codées.]]
creature: {
  label: "critters", sheet: "critter",
  needs: [
    { id: "fuel", icon: "battery", start: 70 },
    { id: "joy",  icon: "joy",     start: 80 },
  ],
  actions: [
    { id: "feed", label: "Feed",
      effects: { fuel: 35, joy: 8 },
      anim: { motion: "nod", particle: "spark" } },
    { id: "play", label: "Play",
      effects: { joy: 22, fuel: -6 },
      anim: { motion: "hop", particle: "star" } },
  ],
  ride: { … },  // [[add it → you can ride it||on l'ajoute → on peut la monter]]
}
  • [[Everything switches on or off. No shop? Don't write one. Want riding? Add ride. Systems you leave out simply disappear.||Tout s'allume ou s'éteint. Pas de boutique ? On n'écrit pas de boutique. Envie d'équitation ? On ajoute ride. Les systèmes absents disparaissent simplement.]]
  • [[Progress benefits every game. When a game needs a new capability, it is added to the engine in a generic way, then copied into every game.||Un progrès profite à tous. Quand un jeu a besoin d'une nouvelle capacité, elle est ajoutée au moteur de façon générique, puis recopiée dans tous les jeux.]]
  • [[Saved games are never lost. Saving is automatic and stays compatible as the game evolves — even through a complete rebuild.||Les parties ne se perdent jamais. La sauvegarde est automatique et reste compatible quand le jeu évolue — même lors d'une refonte complète.]]
  • [[100% static. No server, no build step: the game works offline and is published for free on GitHub Pages.||100 % statique. Aucun serveur, aucune compilation : le jeu marche hors-ligne et se publie gratuitement sur GitHub Pages.]]
